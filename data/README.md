# Data Sources

Raw data files live in `data/raw/` and are **not tracked in git**.
Download each source and place the file at the path shown.

Interim data (`data/interim/`) is generated by the notebooks and also not
tracked. Run notebooks 01--04 to regenerate.

---

## Civil War Onset

### Fearon & Laitin (2003)
- **Coverage:** 1945--1999
- **File:** `data/raw/fl/repdata.dta`
- **Notes:** Primary onset coding. Extended to 2014 using UCDP/PRIO onset
  dates in notebook 01.

---

## Intervention

### Regan (2000) — primary intervention data, 1944--1999
- **File:** `data/raw/regan/replication.10.26.01.dta`
- **Notes:** 424 intervention-dyad records after cleaning (118 biased military
  interventions across civil wars). Two-digit year codes (44--99 -> 1944--1999).

### Post-1999 interventions — hand-coded, 2000--2014
- **File:** `data/raw/regan/post1999_interventions.csv`
- **Notes:** 37 intervention records (25 gov, 12 opp) across 15 host countries.
  Coded by the author using the same criteria as Regan: state must deploy
  personnel (troops/advisors/proxies), must be attributable to a specific COW
  state, must be directed at one side. UN peacekeeping excluded. See comments
  in the CSV for coding justifications and excluded cases.

## State Characteristics

### V-Dem (v14)
- **Coverage:** 1789--2023
- **Download:** https://v-dem.net/data/
- **File:** `data/raw/vdem/V-Dem-CY-Full+Others-v14.csv`
- **Notes:** Source for e_polity2 (extended Polity), e_pt_coup (coup events),
  and pre-period recovery (1942--1945 values for lagged covariates).

### COW National Material Capabilities (v6.0)
- **Coverage:** 1816--2016
- **Download:** https://correlatesofwar.org/data-sets/national-material-capabilities/
- **File:** `data/raw/nmc/NMC-60-abridged.csv`

### COW National Trade (v4.0)
- **File:** `data/raw/cow/national_trade_4.0.csv`

### COW Major Power Status (2024)
- **File:** `data/raw/cow/MajorPowers2024.csv`
- **Notes:** Used for `major_power` indicator. P5 status hard-coded separately.

### Voeten UNGA Ideal Points (Jun 2024)
- **Download:** Harvard Dataverse
- **File:** `data/raw/un-ideals/dataverse_files.zip`
  (contains `IdealpointestimatesAll_Jun2024.csv`)
- **Notes:** Session-level ideal points; year = session + 1945. Goes through
  miceforest imputation in notebook 01.

### Penn World Table / World Bank
- **Notes:** GDP and population data sourced via V-Dem (e_gdp, e_pop).
